# 数据结构-广义表

> [!note] 阅读方式
> 广义表是线性表的推广（教材 4.5），元素可以是"表"本身，形成嵌套结构。概念题为主，重点理解定义。

## 广义表的定义

### 逻辑

广义表（Lists）：线性表的推广，**表中的元素既可以是原子（单个数据），也可以是子表**。

```
L = (a, (b, c), d)
     原子  子表   原子
```

几个关键概念：

| 术语 | 含义 | 例子 L=(a,(b,c),d) |
|---|---|---|
| 表头（head） | 第一个元素 | `a` |
| 表尾（tail） | 除表头外剩余组成的表 | `((b,c), d)` |
| 表长 | 顶层元素个数 | 3 |
| 深度 | 括号嵌套的最大层数 | 2 |

**易错点**：
- **表尾一定是个表**（要加一层括号），表头是单个元素。
- 空表 `()` 和只有一个空子表的表 `(())` 不同，后者表长是 1、深度是 2。

**来源**：教材 4.5.1。

## 广义表的存储结构

### 逻辑

因为元素既可能是原子又可能是子表，节点要能区分这两种情况，常用**"表头表尾"存储法**（每个节点存：是原子还是子表 + 值/指针 + 表尾指针）。

```
节点： tag=0(原子) → 值
      tag=1(子表) → 指向子表
      每个节点还有 next 指向表尾
```

**易错点**：广义表是**递归定义**的结构，天然适合用递归处理（求深度、遍历）。

**来源**：教材 4.5.2。

## 求深度（递归的典型应用）

### 逻辑

深度 = 括号嵌套层数。递归定义：

- 空表深度为 1。
- 原子深度为 0。
- 表的深度 = 各元素深度最大值 + 1。

```cpp
// 概念示意（用嵌套 vector 模拟广义表）
struct GList {
    bool isAtom;
    int atom;               // 原子值
    vector<GList> sub;      // 子表
};

int depth(GList& g) {
    if (g.isAtom) return 0;          // 原子深度 0
    int d = 1;                        // 空表深度 1
    for (auto& e : g.sub)
        d = max(d, depth(e) + 1);
    return d;
}
```

**易错点**：空表深度是 1，原子深度是 0，这是教材的定义，容易记反。

**来源**：教材 4.5。

# 数据结构-循环链表与双向链表

> [!note] 阅读方式
> 单链表基础见 [[数据结构-链表]]。本篇讲循环链表、双向链表，以及顺序表和链表的对比（教材 2.5.3、2.5.4、2.6）。

## 循环链表

### 逻辑

单链表的尾节点 `next` 指向 `nullptr`；循环链表把尾节点的 `next` 指回**头节点**，形成一个环。

好处：从任意节点出发都能遍历完整个链表，尤其适合"约瑟夫问题"这类环形场景。

```
head → [A] → [B] → [C] → (指回 head)
```

### C++ 实现

```cpp
struct Node {
    int val;
    Node* next;
    Node(int v) : val(v), next(nullptr) {}
};

// 判断循环链表是否到"末尾"：不是 next==nullptr，而是 next==head
void print(Node* head) {
    if (!head) return;
    Node* p = head;
    do {
        cout << p->val << " ";
        p = p->next;
    } while (p != head);   // 转一圈回到头就停
}
```

**易错点**：
- 循环链表**没有 nullptr 结尾**，遍历条件要改成 `p != head`，否则死循环。
- 空链表的判断、头尾的处理都比单链表更易错，务必小心。

**来源**：教材第 2 章 2.5.3。

## 双向链表

### 逻辑

单链表每个节点只有一个 `next`（指向后）；双向链表每个节点有 `next`（指向后）和 `prev`（指向前）。

好处：**从后往前遍历、删除当前节点不用找前驱**，是单链表做不到的。

```
head ↔ [A] ↔ [B] ↔ [C] ↔ nullptr
```

### C++ 实现

```cpp
struct Node {
    int val;
    Node* prev;
    Node* next;
    Node(int v) : val(v), prev(nullptr), next(nullptr) {}
};

// 在节点 p 后面插入 v
void insertAfter(Node* p, int v) {
    Node* q = new Node(v);
    q->next = p->next;
    q->prev = p;
    if (p->next) p->next->prev = q;  // 维护后继的 prev
    p->next = q;
}

// 删除节点 p（双向链表能直接删自己，不用找前驱）
void erase(Node* p) {
    if (p->prev) p->prev->next = p->next;
    if (p->next) p->next->prev = p->prev;
    delete p;
}
```

**易错点**：
- 插入/删除要**同时维护 `next` 和 `prev` 两个指针**，漏一个链表就断。
- 删除节点时，前后节点都可能为 `nullptr`（头/尾），要判空。

**来源**：教材第 2 章 2.5.4。

## 顺序表 vs 链表（必考对比）

### 逻辑

| 比较项 | 顺序表（数组/vector） | 链表 |
|---|---|---|
| 存储 | 连续内存 | 分散，靠指针 |
| 随机访问 | O(1) | O(n) |
| 中间插入/删除 | O(n)，要挪元素 | O(1)，改指针（但要先找到位置） |
| 空间 | 无额外开销，但可能浪费预留 | 每个节点多存指针，有开销 |
| 适用 | 频繁查找、随机访问 | 频繁插入删除 |

一句话：**"查得多用顺序表，改得多用链表"**。

**易错点**：
- 链表"插入 O(1)"的前提是**已经定位到位置**；定位本身要 O(n) 遍历。
- 顺序表插入 O(n) 是因为要挪动元素，不是"查找慢"。

**来源**：教材第 2 章 2.6。

# 数据结构-二叉排序树与平衡树

> [!note] 阅读方式
> 树表的查找（教材 7.3）：二叉排序树（BST）和平衡二叉树（AVL）。BST 是基础，AVL 解决 BST 退化问题。

## 二叉排序树（BST）

### 逻辑

BST（二叉搜索树）满足：**左子树所有值 < 根 < 右子树所有值**。中序遍历就是升序序列。

查找、插入都是 O(log n)（平衡时），最坏退化成链表 O(n)。

### C++ 实现

```cpp
struct TreeNode {
    int val;
    TreeNode *left, *right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

// 查找
TreeNode* search(TreeNode* root, int key) {
    if (!root || root->val == key) return root;
    return key < root->val ? search(root->left, key)
                           : search(root->right, key);
}

// 插入
TreeNode* insert(TreeNode* root, int key) {
    if (!root) return new TreeNode(key);
    if (key < root->val) root->left = insert(root->left, key);
    else root->right = insert(root->right, key);
    return root;
}
```

**易错点**：
- 中序遍历 BST 得到**升序**，这是重要性质。
- 直接插入会导致**退化**（如按 1,2,3,4 顺序插入会成一条链），所以要 AVL。

**来源**：教材 7.3.1。

## 平衡二叉树（AVL）

### 逻辑

AVL 树：**任意节点的左右子树高度差（平衡因子）不超过 1**。通过旋转保持平衡，保证 O(log n)。

插入后失衡，四种旋转：
- **LL**（左左）：右旋。
- **RR**（右右）：左旋。
- **LR**（左右）：先左旋再右旋。
- **RL**（右左）：先右旋再左旋。

### C++ 实现（核心：右旋/左旋）

```cpp
int height(TreeNode* n) { return n ? n->height : 0; }
int bf(TreeNode* n) { return height(n->left) - height(n->right); }

TreeNode* rotateRight(TreeNode* y) {   // LL
    TreeNode* x = y->left;
    y->left = x->right;
    x->right = y;
    return x;
}
TreeNode* rotateLeft(TreeNode* x) {    // RR
    TreeNode* y = x->right;
    x->right = y->left;
    y->left = x;
    return y;
}
```

**易错点**：
- **平衡因子 = 左子树高 - 右子树高**，超过 ±1 就失衡。
- LL/RR 一次旋转，LR/RL 两次旋转，判断依据是"新插入节点的位置"。
- 旋转要**返回新根**，并回传给父节点。

**来源**：教材 7.3.2 平衡二叉树。

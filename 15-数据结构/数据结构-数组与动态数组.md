# 数据结构-数组与动态数组

> [!note] 阅读方式
> 本篇（及整个数据结构系列）把「逻辑」和「C++ 实现」分开：先看逻辑想清楚"为什么这么干"，再看代码。代码用 C++17，可单独编译运行。

## 数组：顺序存储

### 逻辑

数组是最基础的结构：**一块连续内存，按下标直接定位**。

核心特点：
- 访问 `a[i]` 是 O(1)——因为知道首地址 + 下标就能算出元素地址（`首地址 + i × 元素大小`）。
- 但插入/删除是 O(n)——中间插一个，后面所有元素都要往后挪。
- 大小固定，创建后不能变长。

一句话：**"随机访问快，插入删除慢，长度固定"**。

### C++ 实现

```cpp
#include <iostream>
using namespace std;

int main() {
    int a[5] = {10, 20, 30, 40, 50};   // 定长数组
    cout << a[2] << "\n";              // 30，O(1) 访问
    a[2] = 99;                         // 修改
    cout << a[2] << "\n";              // 99

    // 遍历
    for (int i = 0; i < 5; i++) {
        cout << a[i] << " ";
    }
    return 0;
}
```

**易错点**：
- 数组越界（`a[5]`）是**未定义行为**，编译器不报错，可能读到垃圾值或崩溃。
- 数组名在多数场合退化成"首元素指针"，但 `sizeof(a)` 是整个数组大小、`sizeof(a[0])` 才是元素大小。

## 动态数组 vector：可变的顺序结构

### 逻辑

数组长度固定太受限，`vector` 解决了"动态扩容"：

- 内部仍是一块连续内存，所以**随机访问还是 O(1)**。
- 末尾追加 `push_back` 是**均摊 O(1)**：满了就申请一块更大的（通常翻倍），把旧数据搬过去。
- 中间插入删除仍是 O(n)（要挪动元素）。
- 关键结论：**vector 下标访问快、末尾操作快、中间操作慢**，和数组一样，只是长度能变。

### C++ 实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;              // 空动态数组
    v.push_back(10);            // 末尾加，均摊 O(1)
    v.push_back(20);
    v.push_back(30);

    cout << v[1] << "\n";       // 20，随机访问 O(1)
    cout << v.size() << "\n";   // 3

    v.insert(v.begin() + 1, 15);  // 中间插入，O(n)
    v.erase(v.begin());           // 删首元素，O(n)

    for (int x : v) cout << x << " ";   // 15 20 30
    return 0;
}
```

**易错点**：
- `v[i]` 不检查越界（越界未定义）；要安全用 `v.at(i)`，越界会抛 `out_of_range`。
- `insert`/`erase` 要传**迭代器**（`v.begin()+i`），不是下标。
- 遍历优先用范围 `for (int x : v)`。

**来源**：cppreference · std::vector（https://en.cppreference.com/w/cpp/container/vector ），2026-10-25 访问。

## 复杂度对比小结

| 操作 | 数组 | vector |
|---|---|---|
| 随机访问 a[i] | O(1) | O(1) |
| 末尾插入 | 不支持 | 均摊 O(1) |
| 中间插入/删除 | O(n) | O(n) |
| 长度 | 固定 | 动态 |

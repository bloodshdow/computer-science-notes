# 数据结构-串与模式匹配

> [!note] 阅读方式
> 串（字符串）的重点是**模式匹配**：在一个主串里找子串的位置（教材 4.3.3）。BF 是暴力法，KMP 是优化。

## 串的基本概念

### 逻辑

- **串**：由字符组成的有限序列，如 `"hello"`。
- **主串**：被查找的长串。
- **子串（模式串）**：要查找的短串。
- **模式匹配**：在主串中定位模式串第一次出现的位置。

在 C++ 里直接用 `std::string`，见 [[Cpp-STL常用容器#string 字符串]]。

## BF 算法（暴力匹配）

### 逻辑

从主串每个位置开始，逐个字符和模式串比较；不匹配就主串回退一位，从头再比。

```
主串: a b a b c
模式:   a b c
第一轮: a==a ✓  b==b ✓  a!=c ✗ → 主串回退到下一个字符重新比
```

### C++ 实现

```cpp
// 返回 pattern 在 text 中第一次出现的位置，找不到返回 -1
int bf(string text, string pattern) {
    int n = text.size(), m = pattern.size();
    for (int i = 0; i <= n - m; i++) {
        int j = 0;
        while (j < m && text[i + j] == pattern[j]) j++;
        if (j == m) return i;   // 完全匹配
    }
    return -1;
}
```

**易错点**：
- 外层循环边界是 `i <= n - m`（最后能放下的位置），不是 `i < n`。
- BF 最坏 O(n·m)，如 `"aaaaab"` 找 `"aaab"` 会大量回退。

**来源**：教材 4.3.3。

## KMP 算法（避免回退）

### 逻辑

BF 的浪费在于：不匹配时主串 `i` 要**回退**。KMP 的核心是让主串指针 `i` **只前进不回退**，靠一个 `next` 数组告诉模式串"该从哪继续比"。

`next[j]` 的含义：模式串前 `j` 个字符里，**最长的"相等前后缀"长度**。不匹配时，模式串跳到 `next[j]` 继续，而不是从头。

一句话：**"主串不动，模式串聪明地跳"**，时间复杂度降到 O(n+m)。

### C++ 实现

```cpp
// 求 next 数组：next[j] = 前 j 个字符的最长相等前后缀长度
vector<int> getNext(string p) {
    int m = p.size();
    vector<int> next(m, 0);
    for (int i = 1, j = 0; i < m; i++) {
        while (j > 0 && p[i] != p[j]) j = next[j - 1];
        if (p[i] == p[j]) j++;
        next[i] = j;
    }
    return next;
}

int kmp(string text, string pattern) {
    vector<int> next = getNext(pattern);
    int n = text.size(), m = pattern.size();
    for (int i = 0, j = 0; i < n; i++) {
        while (j > 0 && text[i] != pattern[j]) j = next[j - 1];
        if (text[i] == pattern[j]) j++;
        if (j == m) return i - m + 1;   // 匹配成功
    }
    return -1;
}
```

**易错点**：
- KMP 的 `next` 数组推导是难点，**建议手推几遍** `"abab"` 的 next 才记得住。
- `while` 回退要用 `next[j-1]`，别写成 `next[j]`（会死循环）。
- 实际开发用 C++ 的 `string::find`（内部是优化过的），KMP 主要是**考试考点**。

**来源**：教材 4.3.3 串的模式匹配算法。

## BF vs KMP

> [!note]- 对比
> | | BF | KMP |
> |---|---|---|
> | 主串指针 | 会回退 | 不回退 |
> | 最坏复杂度 | O(n·m) | O(n+m) |
> | 需要预处理 | 无 | 需 next 数组 |
> | 难易 | 简单 | 较难（考 next 推导） |

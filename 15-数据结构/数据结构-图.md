# 数据结构-图

> [!note] 阅读方式
> 图是比树更一般的结构（教材第 6 章）。重点：两种存储结构 + 两种遍历（DFS/BFS）。

## 图的基本概念

### 逻辑

图 G = (V, E)，V 是顶点集合，E 是边集合。

几个关键术语：
- **有向图/无向图**：边是否有方向。
- **度**：无向图是连接的边数；有向图分入度、出度。
- **连通图**：任意两顶点都连通。
- **路径、回路、简单路径**。
- 带权图（网）：边上有权值。

**易错点**：n 个顶点的无向完全图有 `n(n-1)/2` 条边；有向完全图有 `n(n-1)` 条边。

**来源**：教材 6.1。

## 邻接矩阵

### 逻辑

用 `n×n` 矩阵存图，`g[i][j]` 表示顶点 i 到 j 是否有边（或权值）。

```
0 1 1
1 0 1    →  无向图的邻接矩阵是对称的
1 1 0
```

**优缺点**：判断"i、j 是否相邻"是 O(1)，但空间 O(n²)，稀疏图浪费。

### C++ 实现

```cpp
const int N = 100;
int g[N][N];   // g[i][j] = 1 有边，0 无边（或存权值）

void addEdge(int u, int v) {
    g[u][v] = 1;
    g[v][u] = 1;   // 无向图加两遍
}
```

**易错点**：
- **无向图要对称**（`g[u][v]` 和 `g[v][u]` 都设）。
- 邻接矩阵适合**稠密图**；稀疏图用邻接表省空间。

**来源**：教材 6.4.1。

## 邻接表

### 逻辑

每个顶点维护一个链表，存它连出去的邻居。省空间（O(V+E)），是**最常用**的图存储。

```cpp
vector<vector<int>> adj;   // adj[u] = 顶点 u 的邻居列表

void addEdge(int u, int v) {
    adj[u].push_back(v);
    adj[v].push_back(u);   // 无向图
}
```

**易错点**：无向图加边要加两次（两个方向）；邻接表遍历邻居很快，但判断"是否相邻"要遍历链表。

**来源**：教材 6.4.2。

## 深度优先搜索 DFS

### 逻辑

沿着一条路走到黑，走不通再回溯。用**递归**（或显式栈）实现，标记 visited 避免重复。

```cpp
vector<bool> visited;

void dfs(int u) {
    visited[u] = true;
    cout << u << " ";
    for (int v : adj[u]) {
        if (!visited[v]) dfs(v);   // 递归访问未访问的邻居
    }
}
```

**易错点**：
- **必须标记 visited**，否则会重复访问甚至死循环。
- DFS 适合求连通分量、拓扑排序、路径存在性。

**来源**：教材 6.5.1。

## 广度优先搜索 BFS

### 逻辑

一层层往外扩，用**队列**实现。

```cpp
void bfs(int start) {
    queue<int> q;
    q.push(start);
    visited[start] = true;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        cout << u << " ";
        for (int v : adj[u]) {
            if (!visited[v]) {
                visited[v] = true;
                q.push(v);
            }
        }
    }
}
```

**易错点**：
- BFS 用**队列**（DFS 用递归/栈），别搞混。
- BFS 适合求**无权图的最短路径**（先到的一定最近）。

**来源**：教材 6.5.2。

## DFS vs BFS

> [!note]- 对比
> | | DFS | BFS |
> |---|---|---|
> | 实现 | 递归/栈 | 队列 |
> | 特点 | 一条路走到底 | 层层扩展 |
> | 适用 | 连通分量、拓扑排序 | 最短路径、层序遍历 |

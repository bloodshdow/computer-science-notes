# 数据结构-查找算法

> [!note] 阅读方式
> 线性表的查找（教材 7.2）：顺序查找、折半（二分）查找、分块查找。重点是折半查找。

## 顺序查找

### 逻辑

从前往后一个个比，找到就返回，找不到返回 -1。**无序、有序都能用**。

```cpp
int seqSearch(vector<int>& a, int key) {
    for (int i = 0; i < a.size(); i++)
        if (a[i] == key) return i;
    return -1;
}
```

**易错点**：平均查找长度 O(n)；优点是不要求有序。

**来源**：教材 7.2.1。

## 折半查找（二分查找）

### 逻辑

前提：**数组必须有序**。每次和中间元素比，比中间大就去右半找，小就去左半，每次砍掉一半。O(log n)。

```cpp
int binarySearch(vector<int>& a, int key) {
    int lo = 0, hi = a.size() - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;   // 防溢出
        if (a[mid] == key) return mid;
        else if (a[mid] < key) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
```

**易错点**：
- **必须有序**才能折半，无序数组先排序。
- `mid = lo + (hi - lo) / 2` 防止 `(lo + hi)` 溢出，别写 `(lo+hi)/2`。
- 循环条件 `lo <= hi`（带等号），更新时 `lo = mid + 1`、`hi = mid - 1`（±1 别漏）。

**来源**：教材 7.2.2。

## 二分查找边界变体

> [!note]- 找第一个 / 最后一个等于 key
> ```cpp
> // 第一个 >= key 的位置（lower_bound）
> int lowerBound(vector<int>& a, int key) {
>     int lo = 0, hi = a.size();
>     while (lo < hi) {
>         int mid = lo + (hi - lo) / 2;
>         if (a[mid] < key) lo = mid + 1;
>         else hi = mid;
>     }
>     return lo;
> }
> ```
> 开发中直接用 `std::lower_bound` / `std::upper_bound`（`#include <algorithm>`）。

## 分块查找

### 逻辑

把数据分成若干块，块间有序、块内可无序。先查"块索引"确定在哪块（可折半），再在块内顺序查找。

**易错点**：分块查找是顺序查找和折半查找的折中，适合数据量大的动态查找。

**来源**：教材 7.2.3。

# 数据结构-矩阵压缩存储

> [!note] 阅读方式
> 数组的存储 + 特殊矩阵（对称、三角、稀疏）的压缩（教材 4.4）。核心是"算下标"。

## 数组的顺序存储

### 逻辑

数组在内存里是**连续存储**的，多维数组要"展平"成一维。关键是**行优先**（先存第一行）还是**列优先**（先存第一列）。

以二维数组 `a[m][n]` 行优先为例，元素 `a[i][j]` 的地址：

```
地址 = 首地址 + (i × n + j) × 元素大小
```

**易错点**：行优先是 C/C++ 默认方式（也是教材默认），`a[i][j]` 前面有 `i` 整行 + `j` 个元素。

**来源**：教材 4.4.2。

## 对称矩阵压缩

### 逻辑

对称矩阵满足 `a[i][j] == a[j][i]`，只需存一半（通常是下三角或上三角），省一半空间。

存下三角（含对角线）：只存 `i >= j` 的部分，共 `n(n+1)/2` 个元素。

```
下三角按行优先存成一维数组 b：
a[i][j]（i>=j）→ b[i(i+1)/2 + j]
```

**易错点**：存下三角时，`a[i][j]` 在 `i<j` 时要**转成** `a[j][i]` 再算下标。

**来源**：教材 4.4.3。

## 三角矩阵压缩

### 逻辑

三角矩阵：对角线以上（或以下）全是同一个常数。压缩时存"有效部分 + 常数"，比对称矩阵多存一个常数。

下三角矩阵（上三角全为常数 c）：存下三角 `n(n+1)/2` 个 + 常数 c，共 `n(n+1)/2 + 1` 个。

**来源**：教材 4.4.3。

## 稀疏矩阵与三元组

### 逻辑

稀疏矩阵：非零元素很少（远少于 m×n）。只存**非零元素**，用三元组 `(行, 列, 值)` 表示。

```
稀疏矩阵        三元组（行, 列, 值）
0 0 3 0         (0,2,3)
0 5 0 0   →     (1,1,5)
0 0 0 7         (2,3,7)
```

**易错点**：
- 稀疏矩阵才值得用三元组（省空间）；矩阵不稀疏时三元组反而更慢更复杂。
- 三元组存储牺牲了随机访问，要按行/列遍历。

**来源**：教材 4.4.3（特殊矩阵的压缩存储）。

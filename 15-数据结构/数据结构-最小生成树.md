# 数据结构-最小生成树

> [!note] 阅读方式
> 最小生成树（MST）求连接所有顶点的最小代价（教材 6.6.1）。两种算法：Prim 和 Kruskal。

## 最小生成树的概念

### 逻辑

生成树：包含图所有 n 个顶点、且是**树**（n-1 条边、无环）的连通子图。

最小生成树（MST）：**所有生成树中，边权值之和最小**的那棵。

### 易错点（逻辑层面）

- MST 一定有 `n - 1` 条边。
- 无向连通图才有 MST；MST 可能不唯一，但**总权值唯一**。

**来源**：教材 6.6.1。

## Prim 算法（加点）

### 逻辑

从任意顶点开始，**每次选一条连接"已选点"和"未选点"的最小边**，把新顶点加进来，直到选满 n 个点。

一句话：**"贪心加点，每次挑最近的"**。适合稠密图。

```cpp
// 返回 MST 总权值，g 是邻接矩阵，n 个顶点
int prim(vector<vector<int>>& g, int n) {
    vector<int> dist(n, INT_MAX);   // dist[i] = i 到已选集合的最小距离
    vector<bool> in(n, false);
    dist[0] = 0;
    int total = 0;
    for (int k = 0; k < n; k++) {
        int u = -1;
        for (int i = 0; i < n; i++)           // 选最近的未选点
            if (!in[i] && (u == -1 || dist[i] < dist[u])) u = i;
        in[u] = true;
        total += dist[u];
        for (int v = 0; v < n; v++)           // 更新距离
            if (!in[v] && g[u][v] < dist[v]) dist[v] = g[u][v];
    }
    return total;
}
```

**易错点**：
- `dist[i]` 表示"i 到已选集合的最短距离"，不是到起点。
- 每加一个点，要更新所有未选点的 dist。

**来源**：教材 6.6.1。

## Kruskal 算法（加边）

### 逻辑

**每次选一条不构成环的最小边**，直到选了 n-1 条边。判断成环用**并查集**（见 [[数据结构-并查集]]）。适合稀疏图。

```cpp
struct Edge { int u, v, w; };

int kruskal(vector<Edge>& edges, int n) {
    sort(edges.begin(), edges.end(),   // 按权值升序
         [](Edge& a, Edge& b){ return a.w < b.w; });
    // init 并查集
    vector<int> parent(n);
    for (int i = 0; i < n; i++) parent[i] = i;
    function<int(int)> find = [&](int x) {
        return parent[x] == x ? x : parent[x] = find(parent[x]);
    };
    int total = 0, cnt = 0;
    for (auto& e : edges) {
        int ru = find(e.u), rv = find(e.v);
        if (ru != rv) {          // 不构成环才选
            parent[ru] = rv;
            total += e.w;
            if (++cnt == n - 1) break;
        }
    }
    return total;
}
```

**易错点**：
- 先按权值**排序**是前提。
- 用**并查集**判断两端是否已连通（同根则成环，跳过）。
- 选满 `n-1` 条边就结束。

**来源**：教材 6.6.1。

## Prim vs Kruskal

> [!note]- 对比
> | | Prim | Kruskal |
> |---|---|---|
> | 思路 | 加点 | 加边 |
> | 适合 | 稠密图 | 稀疏图 |
> | 辅助 | dist 数组 | 并查集 |
> | 复杂度 | O(n²) 或 O(E log V) | O(E log E) |

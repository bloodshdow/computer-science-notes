# 数据结构-线索二叉树

> [!note] 阅读方式
> 线索二叉树利用空的左右指针存放"前驱/后继"，加快遍历（教材 5.5.2）。概念理解为主。

## 线索二叉树的思想

### 逻辑

普通二叉树用链式存储时，**有大量空指针**（n 个节点有 2n 个指针，其中 n+1 个是空的）。

线索二叉树的思路：把这些**空的左/右指针**利用起来，指向遍历序列中的**前驱/后继**节点。

- 左指针空 → 指向**中序前驱**。
- 右指针空 → 指向**中序后继**。

这样遍历时不用递归/栈，直接沿着线索走。

### 易错点（逻辑层面）

- 线索指向的是**遍历序列里的前驱/后继**，不是树的父子关系，别搞混。
- 需要额外的标志位（ltag/rtag）区分"指针指向子节点"还是"指向线索"。

**来源**：教材 5.5.2。

## 节点结构与标志位

> [!example]+ 最常用写法
> ```cpp
> struct ThreadNode {
>     int val;
>     ThreadNode *left, *right;
>     bool ltag, rtag;   // false=指向子节点，true=指向线索
>     ThreadNode(int x)
>         : val(x), left(nullptr), right(nullptr),
>           ltag(false), rtag(false) {}
> };
> ```

**用途**：`ltag`/`rtag` 区分指针含义，是线索二叉树的核心设计。

**易错点**：
- `ltag == false` 表示 left 是**左孩子**，`ltag == true` 表示 left 是**前驱线索**。
- 中序线索化后，可以 O(1) 找到某节点的中序后继。

**来源**：教材 5.5.2。

## 中序线索化的思路

### 逻辑

中序线索化 = 在中序遍历过程中，把空指针补成线索。用一个 `pre` 记录**上一个访问的节点**：

- 当前节点左指针空 → 指向 `pre`（前驱）。
- `pre` 的右指针空 → 指向当前节点（后继）。

```cpp
ThreadNode* pre = nullptr;   // 全局记录中序前驱

void inThread(ThreadNode* p) {
    if (!p) return;
    inThread(p->left);            // 线索化左子树
    if (!p->left) {               // 左空 → 指向前驱
        p->left = pre;
        p->ltag = true;
    }
    if (pre && !pre->right) {     // 前驱右空 → 指向当前（后继）
        pre->right = p;
        pre->rtag = true;
    }
    pre = p;                      // 更新前驱
    inThread(p->right);           // 线索化右子树
}
```

**易错点**：
- `pre` 要贯穿整个递归过程（可用全局变量或引用参数）。
- 线索化要**同时改左（前驱）和右（后继）**，缺一不可。

**来源**：教材 5.5.2。

# 数据结构-并查集

> [!note] 阅读方式
> 并查集（Union-Find）处理"集合合并 + 查询归属"问题（教材 5.8），实现极简但极其常用（连通性、最小生成树）。

## 并查集的思想

### 逻辑

维护若干**不相交集合**，支持两个操作：

1. **合并（Union）**：把两个集合合并成一个。
2. **查询（Find）**：判断两个元素是否在同一集合（查它们的"根"）。

用**树形结构**表示集合：每个集合是一棵树，**根节点是集合代表**。判断两元素是否同集合 = 看根是否相同。

### 易错点（逻辑层面）

- "是否连通/同类"问题常能转成并查集。
- 朴素实现查找/合并可能退化成 O(n)，所以要**路径压缩 + 按秩合并**优化（见下）。

**来源**：教材 5.8.1。

## 基础实现

> [!example]+ 最常用写法
> ```cpp
> vector<int> parent;   // parent[i] = i 的父节点，根指向自己
>
> // 初始化：每个元素自成一集合
> void init(int n) {
>     parent.resize(n);
>     for (int i = 0; i < n; i++) parent[i] = i;
> }
>
> // 查找根（朴素）
> int find(int x) {
>     while (parent[x] != x) x = parent[x];
>     return x;
> }
>
> // 合并
> void unite(int a, int b) {
>     parent[find(a)] = find(b);
> }
> ```

**用途**：最基本的并查集。`parent[x] == x` 表示 x 是根。

**易错点**：
- 初始化时每个元素**父节点指向自己**（自成集合）。
- 合并是把**一个根挂到另一个根下**，不是挂到元素本身。

**来源**：教材 5.8.2。

## 优化：路径压缩 + 按秩合并

### 逻辑

- **路径压缩**：`find` 时把沿途节点都直接指向根，之后查询近 O(1)。
- **按秩合并**：把小树挂到大树下，避免退化成链。

两者结合，`find`/`unite` 近似 **O(α(n))**（α 是反阿克曼函数，几乎常数）。

```cpp
vector<int> parent, rank_;

int find(int x) {                     // 路径压缩
    if (parent[x] != x)
        parent[x] = find(parent[x]);  // 递归压缩，直接指向根
    return parent[x];
}

void unite(int a, int b) {            // 按秩合并
    int ra = find(a), rb = find(b);
    if (ra == rb) return;
    if (rank_[ra] < rank_[rb]) swap(ra, rb);
    parent[rb] = ra;
    if (rank_[ra] == rank_[rb]) rank_[ra]++;
}
```

**易错点**：
- 路径压缩的 `find` 要**赋值** `parent[x] = find(parent[x])`，不是只调用。
- `rank_` 不是树的高度，是"上界"，合并时只有相等才 +1。

**来源**：教材 5.8.2 并查集的实现及优化。

## 典型应用

> [!note]- 什么时候用并查集
> - 判断无向图两点是否连通。
> - 最小生成树 Kruskal 算法判断是否成环。
> - 朋友圈问题、岛屿数量等 LeetCode 题。
> - 核心套路：初始化 n 个集合 → 逐个合并 → 查根判断。

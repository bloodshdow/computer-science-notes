# 数据结构-复杂度分析

> [!note] 阅读方式
> 复杂度是评价算法好坏的核心（教材第 1 章）。先讲清楚"为什么"，再看怎么算。这是后面所有算法分析的基石。

## 时间复杂度：大 O 表示法

### 逻辑

衡量一个算法**随数据量增长，运行时间增长得多快**，用大 O 表示"上界"。

我们不关心具体跑几秒（受机器影响），只关心**增长趋势**：

| 复杂度 | 名称 | n=1000 时 | 说明 |
|---|---|---|---|
| O(1) | 常数 | 1 | 和 n 无关 |
| O(log n) | 对数 | ~10 | 每次砍一半 |
| O(n) | 线性 | 1000 | 一次循环 |
| O(n log n) | 线性对数 | ~10000 | 快排、归并 |
| O(n²) | 平方 | 100万 | 双重循环 |
| O(2ⁿ) | 指数 | 天文数字 | 暴力枚举，n 稍大就崩 |

一句话：**"看最高阶，忽略常数和低阶项"**。

### 怎么算

> [!example]+ 判断方法
> ```cpp
> // O(1)：常数次操作，没有循环
> int x = a[0];
>
> // O(n)：一层循环
> for (int i = 0; i < n; i++) { sum += a[i]; }
>
> // O(n²)：两层嵌套循环
> for (int i = 0; i < n; i++)
>     for (int j = 0; j < n; j++) { }
>
> // O(log n)：每次规模减半
> while (n > 1) { n /= 2; }
> ```

**易错点**：
- **只看最高阶**：`3n² + 5n + 2` 记作 O(n²)，常数 3 和低阶项都去掉。
- 嵌套循环是**相乘**（n×n=n²），并列循环是**相加**（n+n=2n→O(n)）。
- 循环变量每次乘 2（或除 2）是 O(log n)，不是 O(n)。

**版本/平台**：通用算法知识（教材第 1 章）。

**来源**：李冬梅、严蔚敏《数据结构（C语言版）第3版》第 1 章，人民邮电出版社 2024。

## 空间复杂度

### 逻辑

衡量算法**额外占用的内存**随 n 的增长，同样用大 O。

- 只用了几个变量 → O(1)。
- 开了个长度为 n 的数组 → O(n)。
- 递归深度为 n → O(n)（递归调用栈占用）。

**易错点**：
- 空间复杂度看的是**额外**空间，输入的原始数组不算。
- 递归算法要算上**调用栈**的开销，深度 n 的递归是 O(n) 空间。

**来源**：同教材第 1 章 1.4.4。

## 常见复杂度速查

> [!note]- 各种算法复杂度对照
> | 操作/算法 | 平均时间 | 最坏时间 | 空间 |
> |---|---|---|---|
> | 顺序查找 | O(n) | O(n) | O(1) |
> | 折半查找 | O(log n) | O(log n) | O(1) |
> | 直接插入排序 | O(n²) | O(n²) | O(1) |
> | 冒泡排序 | O(n²) | O(n²) | O(1) |
> | 快速排序 | O(n log n) | O(n²) | O(log n) |
> | 归并排序 | O(n log n) | O(n log n) | O(n) |
> | 堆排序 | O(n log n) | O(n log n) | O(1) |
> | 二叉树遍历 | O(n) | O(n) | O(n) |

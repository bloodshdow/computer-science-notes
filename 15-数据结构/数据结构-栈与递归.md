# 数据结构-栈与递归

> [!note] 阅读方式
> 递归和栈关系密切（教材 3.4）。先理解递归原理，再看"递归工作栈"和"递归转非递归"。

## 递归的原理

### 逻辑

递归 = 函数**自己调用自己**，直到某个"终止条件"（base case）停止。

两个必备要素：
1. **终止条件**：什么时候不再递归（否则死循环栈溢出）。
2. **递归式**：把大问题拆成更小的同类问题。

经典例子：阶乘 `n! = n × (n-1)!`，终止条件是 `n == 1`。

### C++ 实现

```cpp
// 递归求阶乘
int fact(int n) {
    if (n <= 1) return 1;        // 终止条件
    return n * fact(n - 1);      // 递归式
}

// 递归求斐波那契
int fib(int n) {
    if (n <= 1) return n;
    return fib(n - 1) + fib(n - 2);
}
```

**易错点**：
- **必须有终止条件**，否则无限递归导致栈溢出（Stack Overflow）。
- 斐波那契递归是 O(2ⁿ) 指数复杂度，因为重复计算（`fib(3)` 被算多次），别在生产里用。

**来源**：教材第 3 章 3.4。

## 递归工作栈

### 逻辑

每次递归调用，系统会：
1. 把当前函数的**局部变量、参数、返回地址**压入"调用栈"。
2. 进入新的递归层。
3. 递归返回时，从栈顶弹出，恢复上一层现场。

所以递归深度 = 栈的深度。**递归深度太大 → 栈溢出**。这就是为什么递归本质上是"系统帮你用栈"。

**易错点**：递归空间复杂度 = 递归深度（调用栈占用），深度 n 就是 O(n) 空间。

**来源**：教材 3.4.2。

## 递归转非递归（用显式栈）

### 逻辑

既然递归靠系统栈，那我们**自己维护一个栈**，就能把递归改写成循环，避免系统栈溢出，也能控制空间。

以二叉树前序遍历为例（详见 [[数据结构-二叉树]]）：

```cpp
// 递归版
void preorder(Node* root) {
    if (!root) return;
    visit(root);
    preorder(root->left);
    preorder(root->right);
}

// 非递归版（显式栈）
void preorder2(Node* root) {
    stack<Node*> st;
    st.push(root);
    while (!st.empty()) {
        Node* p = st.top(); st.pop();
        if (!p) continue;
        visit(p);
        st.push(p->right);   // 先压右，后压左，出栈顺序才对
        st.push(p->left);
    }
}
```

**易错点**：
- 前序非递归要**先压右子、再压左子**，因为栈是后进先出。
- 递归转非递归的通用思路：**用显式栈模拟系统调用栈**。

**来源**：教材 3.4.4。

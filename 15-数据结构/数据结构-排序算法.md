# 数据结构-排序算法

> [!note] 阅读方式
> 内部排序（教材第 8 章）。按类别：插入、交换、选择、归并、基数。重点是每种的时间复杂度和稳定性。

## 排序总览（先记这张表）

| 排序 | 平均时间 | 最坏时间 | 空间 | 稳定性 |
|---|---|---|---|---|
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 希尔 | O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 快速 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 简单选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 堆 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(n+r) | 稳定 |

**记忆要点**：O(n log n) 的三个（快排、堆、归并）里，**只有归并稳定且需要 O(n) 空间**；快排最坏 O(n²)。

**来源**：教材第 8 章。

## 插入类：直接插入、希尔

```cpp
// 直接插入排序（稳定）
void insertSort(vector<int>& a) {
    for (int i = 1; i < a.size(); i++) {
        int key = a[i], j = i - 1;
        while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }
        a[j + 1] = key;
    }
}
```

**易错点**：插入排序把当前元素插入"前面已排好的部分"，基本有序时接近 O(n)。

## 交换类：冒泡、快速

```cpp
// 冒泡排序（稳定）
void bubbleSort(vector<int>& a) {
    for (int i = 0; i < a.size() - 1; i++)
        for (int j = 0; j < a.size() - 1 - i; j++)
            if (a[j] > a[j + 1]) swap(a[j], a[j + 1]);
}

// 快速排序（不稳定，最常用）
int partition(vector<int>& a, int lo, int hi) {
    int pivot = a[lo];
    while (lo < hi) {
        while (lo < hi && a[hi] >= pivot) hi--;
        a[lo] = a[hi];
        while (lo < hi && a[lo] <= pivot) lo++;
        a[hi] = a[lo];
    }
    a[lo] = pivot;
    return lo;
}
void quickSort(vector<int>& a, int lo, int hi) {
    if (lo >= hi) return;
    int p = partition(a, lo, hi);
    quickSort(a, lo, p - 1);
    quickSort(a, p + 1, hi);
}
```

**易错点**：
- 快排最坏 O(n²) 出现在**基本有序**时（每次都选到最小/最大当 pivot），随机化或三数取中可避免。
- 快排不稳定（相等元素可能换位）。

## 选择类：简单选择、堆

```cpp
// 简单选择排序（不稳定）
void selectSort(vector<int>& a) {
    for (int i = 0; i < a.size() - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < a.size(); j++)
            if (a[j] < a[minIdx]) minIdx = j;
        swap(a[i], a[minIdx]);
    }
}

// 堆排序（不稳定，O(n log n)）
void heapify(vector<int>& a, int n, int i) {
    int largest = i, l = 2 * i + 1, r = 2 * i + 2;
    if (l < n && a[l] > a[largest]) largest = l;
    if (r < n && a[r] > a[largest]) largest = r;
    if (largest != i) { swap(a[i], a[largest]); heapify(a, n, largest); }
}
void heapSort(vector<int>& a) {
    int n = a.size();
    for (int i = n / 2 - 1; i >= 0; i--) heapify(a, n, i);  // 建堆
    for (int i = n - 1; i > 0; i--) { swap(a[0], a[i]); heapify(a, i, 0); }
}
```

**易错点**：
- 堆用**数组**存储，下标 i 的左右子是 `2i+1`、`2i+2`（从 0 开始）。
- 堆排序"建堆 + 反复取堆顶"，空间 O(1)，是"原地"的 O(n log n)。

## 归并排序

```cpp
// 归并排序（稳定，O(n log n)，需要 O(n) 空间）
void merge(vector<int>& a, int lo, int mid, int hi) {
    vector<int> tmp(hi - lo + 1);
    int i = lo, j = mid + 1, k = 0;
    while (i <= mid && j <= hi)
        tmp[k++] = a[i] <= a[j] ? a[i++] : a[j++];
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= hi) tmp[k++] = a[j++];
    for (int p = 0; p < k; p++) a[lo + p] = tmp[p];
}
void mergeSort(vector<int>& a, int lo, int hi) {
    if (lo >= hi) return;
    int mid = lo + (hi - lo) / 2;
    mergeSort(a, lo, mid);
    mergeSort(a, mid + 1, hi);
    merge(a, lo, mid, hi);
}
```

**易错点**：归并是**稳定**且最坏 O(n log n) 的，缺点是额外 O(n) 空间；用 `<=` 合并才保证稳定。

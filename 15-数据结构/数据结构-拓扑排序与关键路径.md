# 数据结构-拓扑排序与关键路径

> [!note] 阅读方式
> 图的应用（教材 6.6.3、6.6.4）：拓扑排序处理依赖关系，关键路径用于工程工期分析。

## 拓扑排序

### 逻辑

**拓扑排序**：把有向无环图（DAG）的顶点排成一个序列，使每条边的起点都在终点前面。

前提：**必须是有向无环图（DAG）**，有环则无法拓扑排序。

典型场景：课程依赖（先修课）、任务调度。

### C++ 实现（Kahn 算法，用入度）

```cpp
// 返回拓扑序列，若不存在（有环）返回空
vector<int> topoSort(int n, vector<vector<int>>& adj) {
    vector<int> indeg(n, 0);
    for (int u = 0; u < n; u++)
        for (int v : adj[u]) indeg[v]++;   // 统计入度

    queue<int> q;
    for (int i = 0; i < n; i++)
        if (indeg[i] == 0) q.push(i);      // 入度为 0 的先入队

    vector<int> order;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        order.push_back(u);
        for (int v : adj[u])
            if (--indeg[v] == 0) q.push(v);  // 去掉 u 后入度变 0
    }
    return order.size() == n ? order : vector<int>{};  // 不足 n 说明有环
}
```

**易错点**：
- 最终序列长度**不足 n** 说明有环，无法拓扑排序。
- 每次取出入度为 0 的点，并把它指向的点的入度减 1。

**来源**：教材 6.6.3。

## 关键路径（AOE 网）

### 逻辑

**AOE 网**：带权的有向无环图，顶点表示事件，边表示活动（权值 = 活动持续时间）。

**关键路径**：从起点到终点**最长的路径**（决定整个工程的最短工期）。

四个量：
- `ve`（事件最早发生时间）：从前往后推，取 max。
- `vl`（事件最迟发生时间）：从后往前推，取 min。
- `e`（活动最早开始）= 起点的 ve。
- `l`（活动最迟开始）= 终点的 vl - 权值。

**关键活动**：满足 `e == l` 的活动，它们连起来就是关键路径。

### 易错点（逻辑层面）

- 关键路径是**最长**路径，不是最短（别和最短路径混）。
- 关键活动延迟会延误整个工期；非关键活动有一定余量（`l - e`）。
- 关键路径可能**不止一条**。

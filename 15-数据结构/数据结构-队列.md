# 数据结构-队列

> [!note] 阅读方式
> 队列是**先进先出（FIFO）**的线性结构（教材第 3 章）。栈见 [[数据结构-栈]]，两者对比是常见考点。

## 队列的核心思想

### 逻辑

队列像排队：**先进来的先出去**。只能在一端（队尾）插入，另一端（队头）删除。

两个操作：
- **入队（enqueue）**：在队尾加元素。
- **出队（dequeue）**：从队头删元素。

### 易错点（逻辑层面）

- 队列先进先出（FIFO），栈后进先出（LIFO），这是最常考的对比。
- 普通数组做队列，出队后前面空出来浪费，所以要**循环队列**（见下）。

## 用 STL 的 queue

> [!example]+ 最常用写法
> ```cpp
> #include <queue>
> queue<int> q;
> q.push(10);        // 入队（队尾）
> q.push(20);
> q.front();         // 10，队头（不删除）
> q.pop();           // 出队（删队头）
> q.back();          // 20，队尾
> q.empty();         // 是否空
> q.size();          // 大小
> ```

**易错点**：
- `pop()` 不返回值，先 `front()` 取值再 `pop()`。
- 空队列调用 `front()`/`pop()` 是未定义行为，先判 `empty()`。

**来源**：cppreference · std::queue（https://en.cppreference.com/w/cpp/container/queue ），2026-10-25 访问。

## 循环队列（重点，考试常考）

### 逻辑

用**定长数组**实现队列，出队后不挪动元素，而是让队头、队尾指针**在数组里绕圈**（到末尾回到开头），从而复用出队空出的空间。

```
[ ][B][C][ ]   front 指向 B，rear 指向 C 的下一个空位
队尾指针 rear 到数组末尾后，模运算绕回 0
```

关键公式：
- 入队：`rear = (rear + 1) % size`
- 出队：`front = (front + 1) % size`
- 判满：`(rear + 1) % size == front`（牺牲一个位置区分空满）

### C++ 实现

```cpp
class CircularQueue {
    int *data;
    int front, rear, cap;   // cap = 数组容量
public:
    CircularQueue(int k) : cap(k + 1), front(0), rear(0) {
        data = new int[cap];   // 多开 1 个位置区分空/满
    }
    bool empty() { return front == rear; }
    bool full() { return (rear + 1) % cap == front; }
    bool enqueue(int x) {
        if (full()) return false;
        data[rear] = x;
        rear = (rear + 1) % cap;
        return true;
    }
    bool dequeue() {
        if (empty()) return false;
        front = (front + 1) % cap;
        return true;
    }
    int getFront() { return empty() ? -1 : data[front]; }
};
```

**易错点**：
- **判满用"牺牲一个位置"**：`(rear+1)%cap == front`，所以数组要开 `k+1`。
- 所有移动都要 `% cap`，否则指针会越界。
- `empty` 判 `front == rear`，和"牺牲一个位置"的判满规则配套。

**来源**：教材第 3 章 3.5.2 顺序队；LeetCode 622 设计循环队列。

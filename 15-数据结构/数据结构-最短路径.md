# 数据结构-最短路径

> [!note] 阅读方式
> 求两点间最短路径（教材 6.6.2）。两个经典算法：Dijkstra（单源、无负权）和 Floyd（多源）。

## Dijkstra 算法（单源最短路径）

### 逻辑

求**一个起点到其他所有点**的最短距离，贪心思想：**每次选当前距离最小的未确定点**，用它更新邻居。

前提：**边权非负**（有负权会失效）。

```cpp
// g 邻接矩阵，dist 存起点到各点最短距离
void dijkstra(vector<vector<int>>& g, int src, int n) {
    vector<int> dist(n, INT_MAX);
    vector<bool> done(n, false);
    dist[src] = 0;
    for (int k = 0; k < n; k++) {
        int u = -1;
        for (int i = 0; i < n; i++)           // 选未确定的最近点
            if (!done[i] && (u == -1 || dist[i] < dist[u])) u = i;
        done[u] = true;
        for (int v = 0; v < n; v++)           // 松弛：经 u 是否更近
            if (!done[v] && g[u][v] != INT_MAX)
                dist[v] = min(dist[v], dist[u] + g[u][v]);
    }
}
```

**易错点**：
- **不能有负权边**，否则结果错误（有负权用 Bellman-Ford / SPFA）。
- "松弛"操作 `dist[v] = min(dist[v], dist[u] + w)` 是核心。
- 朴素 O(n²)；用**优先队列**可优化到 O(E log V)。

**来源**：教材 6.6.2。

## Floyd 算法（多源最短路径）

### 逻辑

求**任意两点之间**的最短距离，三重循环，动态规划思想：**依次允许每个点作为中转点**。

```cpp
// g 初始为邻接矩阵，之后 g[i][j] 变为 i 到 j 的最短距离
void floyd(vector<vector<int>>& g, int n) {
    for (int k = 0; k < n; k++)           // 中转点
        for (int i = 0; i < n; i++)
            for (int j = 0; j < n; j++)
                if (g[i][k] != INT_MAX && g[k][j] != INT_MAX)
                    g[i][j] = min(g[i][j], g[i][k] + g[k][j]);
}
```

**易错点**：
- **中转点 k 在最外层循环**，顺序不能错。
- 时间复杂度 O(n³)，只适合顶点数少的图。
- 对角线 `g[i][i]` 初始为 0。

**来源**：教材 6.6.2。

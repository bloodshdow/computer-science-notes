# 数据结构-哈夫曼树

> [!note] 阅读方式
> 哈夫曼树（最优二叉树）用于哈夫曼编码、数据压缩（教材 5.7）。核心是"带权路径长度最小"。

## 哈夫曼树的概念

### 逻辑

几个概念先理清：

- **路径长度**：从根到某节点的分支数。
- **带权路径长度（WPL）**：节点权值 × 到根的路径长度，求和。
- **哈夫曼树**：给定一组权值，构造的 **WPL 最小**的二叉树。

一句话：**"让权重大的节点离根近，总的带权路径就短"**。

### 易错点（逻辑层面）

- WPL 是**所有权值叶子的带权路径之和**，非叶子不算。
- 哈夫曼树不唯一（构造时选择顺序不同），但 **WPL 唯一且最小**。

**来源**：教材 5.7.1。

## 构造算法

### 逻辑

贪心思想，反复"取两个最小的合并"：

1. 把 n 个权值看成 n 棵单节点树，放入集合。
2. 每次取出**权值最小的两棵**，合并成一棵新树（新根权值 = 两者之和）。
3. 重复直到只剩一棵树。

### C++ 实现（用优先队列）

```cpp
#include <queue>
#include <vector>
using namespace std;

// 返回哈夫曼树的 WPL（带权路径长度）
int huffmanWPL(vector<int> weights) {
    priority_queue<int, vector<int>, greater<int>> pq;  // 小顶堆
    for (int w : weights) pq.push(w);

    int wpl = 0;
    while (pq.size() > 1) {
        int a = pq.top(); pq.pop();
        int b = pq.top(); pq.pop();
        int sum = a + b;
        wpl += sum;      // 每次合并的权值和累加就是 WPL
        pq.push(sum);
    }
    return wpl;
}
```

**易错点**：
- 用**小顶堆（优先队列）**每次取最小两个，是标准做法。
- WPL 等于**所有合并产生的"父节点权值"之和**，这个技巧能省去逐叶计算。
- n 个叶子的哈夫曼树有 `2n - 1` 个节点。

**来源**：教材 5.7.2。

## 哈夫曼编码

### 逻辑

用哈夫曼树做**前缀编码**：左分支记 0，右分支记 1，每个叶子的编码就是"根到它的路径"。

- 出现频率高的字符权值大、路径短、编码短 → 总编码长度最小。
- **前缀编码**：任一编码都不是另一编码的前缀（因为编码只在叶子，不会在中间节点）。

### 易错点

- 哈夫曼编码是**前缀码**，所以能无歧义解码。
- 左 0 右 1 是约定，反过来（左 1 右 0）也对，关键是统一。

**来源**：教材 5.7.3。
